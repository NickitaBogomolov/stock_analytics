Тесты с PostgreSQL включаются переменной `MARKET_TEST_DB_URL` (в CI — сервис-контейнер Postgres,
в Docker — `docker compose --profile test run --rm tests`); без неё они помечаются skipped.

Запуск:

```bash
cmake -S core-cpp -B core-cpp/build && cmake --build core-cpp/build -j && ctest --test-dir core-cpp/build
cd web-kotlin && ./gradlew test
```

С PostgreSQL:

```bash
MARKET_TEST_DB_URL=jdbc:postgresql://localhost:5432/market_test MARKET_TEST_DB_USER=market MARKET_TEST_DB_PASSWORD=market ./gradlew test
```

Результат последнего прогона: **C++ — 51/51 passed, Kotlin — 119/119 passed, 0 skipped**
(с PostgreSQL 16 и собранным `market_cli`).

## 4.2 Граничные случаи

| Категория | Случаи |
|---|---|
| Периоды | 0 → ошибка; period = 1 → исходный ряд; period = размер ряда → одно значение; period > размера → ошибка |
| RSI | только рост → 100; только падение → 0; цены не меняются → 50; данных ровно period → ошибка |
| Волатильность / Шарп | 1 доходность → ошибка; постоянная доходность → σ = 0, Шарп = 0 (без деления на 0) |
| Просадка | монотонный рост → 0; пустой ряд → 0; несколько пиков → максимальная |
| Длина ряда в анализе | ровно `max(slow, rsi)+1` → успех; на 1 меньше → 422 |
| Хранилище | повторный импорт (замена), удаление с каскадом, запуск для несуществующего инструмента, нарушение `CHECK` (откат всей транзакции), `limit` 0 / 201 |
| CSV | пустой файл; только заголовок; нет заголовка; 5 и 7 колонок; пустое поле; `abc`, `11x`, `NaN`, `0x0A`, `11d`; дата `02.01.2024`, месяц 13, `2023-02-29`, `2024-04-31` (и корректная `2024-02-29`); цена 0 и < 0; high < open; low > close; объём < 0 и дробный; повтор/убывание дат; CRLF, пробелы, пустые строки |
| API | `fast=abc`, `fast=0`, `rf=nan`, `engine=java`, fast ≥ slow, неизвестный тикер, `..%2Fsecret`, C++ недоступен, 1 тикер в сравнении |

## 4.3 Найденные дефекты

| ID | Серьёзность | Описание | Как найден | Исправление | Статус |
|---|---|---|---|---|---|
| D-01 | Высокая | Графики не отображаются без доступа к CDN (Chart.js грузился с cdnjs) — в изолированной сети страница без графиков | Ручной прогон UI в headless Chromium | Chart.js 4.4.1 поставляется локально (`static/vendor`), сообщение об ошибке, если скрипт не загрузился | Исправлен |
| D-02 | Средняя | C++ `std::stod` принимал `0x0A` (=10) как цену; Kotlin `toDoubleOrNull` — `0x1p3`, `NaN`, `11d` | Тест-кейсы на некорректные числа при портировании | Белый список символов `[0-9.eE+-]` в обеих реализациях; добавлены тесты | Исправлен |
| D-03 | Низкая | На графике RSI скрывались подписи уровней 30/70 (автопропуск делений Chart.js) | Визуальная проверка скриншота | `ticks.autoSkip = false` | Исправлен |
| D-04 | Низкая | Демо-данные: корреляции бумаг ≈ 0 (нереалистично, матрица корреляций неинформативна) | Проверка экрана «Сравнение» | В генератор добавлен общий рыночный фактор (бета 0.35–0.75) | Исправлен |
| D-05 | Низкая | Предупреждение компилятора `-Wformat-truncation` в тестовом помощнике | Сборка с `-Wall -Wextra` | Увеличен буфер | Исправлен |
| D-06 | Средняя | Несуществующие даты (`2024-02-30`, `2023-02-29`) проходили проверку CSV, а PostgreSQL `DATE` их отвергает — импорт падал бы с 500 вместо 422 | Проектирование хранения в БД | Проверка реальной календарной даты в C++ и Kotlin (високосные годы), новые тесты | Исправлен |
| D-07 | Средняя | При удалении бумаги в PostgreSQL оставались «осиротевшие» расчёты лаборатории без тикеров (в памяти — удалялись) | Контрактный тест хранилища на двух реализациях | Удаление связанных `lab_run` в той же транзакции | Исправлен |
| D-08 | Средняя | Вкладки внутри лаборатории перехватывались обработчиком основных вкладок — страница становилась пустой; `display:flex` перебивал атрибут `hidden` | UI-проверка в headless Chromium | Обработчик только для `.tabs .tab`, правило `[hidden] { display: none !important }` | Исправлен |

## 4.4 Известные ограничения

- Живой ISS API Мосбиржи в автотестах не вызывается (нужен интернет, данные меняются): клиент проверяется на локальной заглушке того же формата.

- Годовая нормировка использует 252 торговых дня независимо от биржевого календаря.
- Сигналы пересечения SMA — учебная модель, без учёта комиссий и проскальзывания.
