    Квант-лаборатория

    Тяжёлые расчёты выполняет C++ модуль market_cli: перебор сотен вариантов стратегии, десятки тысяч сценариев и портфелей. Kotlin-сервис берёт котировки из PostgreSQL, передаёт их в C++ и сохраняет результат в историю.

    Стратегия: держать бумагу, пока SMA(fast) выше SMA(slow). C++ перебирает пары fast 2…50 и slow 10…250, выбирает лучшую по Шарпу на первой части истории и честно проверяет её на оставшейся части, которую при подборе «не видел».

    Бутстреп: будущие дни собираются из случайно выбранных исторических дневных доходностей. Получаем распределение цены через N дней, VaR (потеря, которую не превысим с вероятностью 95 / 99 %) и CVaR (средняя потеря в худших 5 / 1 % случаев).

    Случайный поиск по долям бумаг (только покупка, сумма 100 %): C++ оценивает доходность и риск каждого портфеля по ковариационной матрице и находит портфель с максимальным коэффициентом Шарпа и с минимальным риском.
